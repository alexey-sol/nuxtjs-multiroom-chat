# nuxtjs-multiroom-chat

> A simple multiroom chat built with Nuxt.js

## Scripts

### `npm run dev`

Start the application in development mode. It gets served at `localhost:3000`.

### `npm run build`
### `npm run start`

Build for production and launch server.

### `npm run generate`

Generate static project.

### `npm run demo:up`
### `npm run demo:down`
### `npm run demo:restart`

Start/stop/restart the application in Docker container. It gets exposed on port `15501`.

### `npm run lint`

Lint the code.
